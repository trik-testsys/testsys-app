# Добавление веб-компонента

Гайд ведёт разработчика от контракта нового компонента до его реализации в DSL с оформлением, текстами
и контрактными тестами. Создание страницы из готовых компонентов описано
в [implement-web-page.md](implement-web-page.md).

## Чек-лист

| # | Шаг | Место изменения |
|---|-----|-----------------|
| 1 | Определить контракт | API компонента |
| 2 | Добавить DSL и ручку | Пакет группы в components |
| 3 | Добавить оформление | Общие ресурсы testsys-ui |
| 4 | Добавить встроенные тексты | Пакет texts, если нужны новые подписи |
| 5 | Проверить контракт | Тесты components |

## 1. Определить контракт

Определите смысл, состояния и размещения по требованиям и ближайшему компоненту. Проверьте раздел
[Граница конфигурации](../../testsys-web/components/README.md#граница-конфигурации).

## 2. Добавить DSL и ручку

Добавьте расширение скоупа в пакет группы по разделам
[Скоупы](../../testsys-web/components/README.md#скоупы) и
[Ручки и служебные свойства](../../testsys-web/components/README.md#ручки-и-служебные-свойства).

## 3. Добавить оформление

Измените общие ресурсы из раздела [Устройство](../../testsys-web/components/README.md#устройство).
Для клиентского поведения следуйте разделу
[Клиентская реализация компонентов](../../testsys-web/components/README.md#клиентская-реализация-компонентов).
Правила оформления — в [ui-design.md](../project/ui-design.md).

## 4. Добавить встроенные тексты

Если компоненту нужны новые встроенные подписи, добавьте их по разделу
[Тексты](../../testsys-web/components/README.md#тексты).

## 5. Проверить контракт

Добавьте тесты по разделу [Проверка компонентов](../../testsys-web/components/README.md#проверка-компонентов).
Соглашения тестов — в [unit-tests.md](../project/unit-tests.md), сборка — в
[structure.md](../project/structure.md#сборка).
