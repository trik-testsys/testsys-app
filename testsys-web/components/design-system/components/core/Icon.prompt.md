Lucide line icon (bundled subset) — use for every glyph in TestSys UI; inherits currentColor.
```jsx
<Icon name="download" size={16} />
```
Sizes: 14 (small controls), 16 (default), 18 (header), 22 (empty states). Need an icon outside the subset? Use lucide-react or the Lucide CDN with the same 2px stroke.
