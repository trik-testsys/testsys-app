# Approval for component changes

These instructions govern agent changes to `testsys-web:components` (`testsys-web/components/`).

Before editing any maintained file in this module, describe the proposed changes and obtain the user's explicit
approval. This includes implementation, public APIs, styles, client code, tests, resources and documentation.
A general request to change an application page does not authorize changes to the component module.

Approval of a plan that explicitly describes the component changes authorizes those changes; do not request the
same approval again. If additional component changes become necessary, explain them and obtain approval before
applying them. Delegated agents must return unapproved component changes to their coordinator and may continue
independent work within the approved scope.

Reading files and running checks or builds do not require this approval. Generated build outputs are not maintained
files and are outside this editing rule.
