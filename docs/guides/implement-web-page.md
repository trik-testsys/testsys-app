# Создание веб-страницы

Гайд ведёт разработчика от сценария до проверенной страницы на публичном Kotlin DSL основного приложения.
Добавление нового компонента описано в [add-web-component.md](add-web-component.md).

## Чек-лист

| # | Шаг | Место изменения |
|---|-----|-----------------|
| 1 | Определить сценарий и Роль | Требования страницы |
| 2 | Выбрать пакет | app |
| 3 | Объявить маршрут и жизненный цикл | Класс страницы |
| 4 | Собрать страницу на публичном DSL | Класс страницы и её секции |
| 5 | Настроить тексты, состояния и действия | Страница и используемые ручки |
| 6 | Проверить страницу | Тесты app |

## 1. Определить сценарий и Роль

Определите данные, действия, состояния и Роль Пользователя по задаче и соответствующей фиче в
[features.md](../domain/features.md). Термины — в [definitions.md](../domain/definitions.md).
Если задача включает новую пользовательскую операцию, примените [implement-feature.md](implement-feature.md).
Текущие границы реализации основного приложения — в [app/README.md](../../testsys-web/app/README.md).

## 2. Выбрать пакет

Место кода — по разделу [Куда класть новый код](../project/structure.md#куда-класть-новый-код).
Пакеты и назначение страниц описаны в [app/README.md](../../testsys-web/app/README.md).

## 3. Объявить маршрут и жизненный цикл

Создайте класс страницы по разделу [Страница](../../testsys-web/components/README.md#страница).
Если маршрут принимает параметры, следуйте разделу
[Страницы с параметром маршрута](../../testsys-web/components/README.md#страницы-с-параметром-маршрута).
Для фоновых обновлений проверьте подключение и отключение подписок по разделу
[Живые обновления](../../testsys-web/components/README.md#живые-обновления).

## 4. Собрать страницу на публичном DSL

Выберите композицию по разделам [Сетка](../../testsys-web/components/README.md#сетка) и
[Скоупы](../../testsys-web/components/README.md#скоупы), затем прочитайте API нужных компонентов.
Проверьте раздел [Граница конфигурации](../../testsys-web/components/README.md#граница-конфигурации).
Если нужного представления нет в API, примените [add-web-component.md](add-web-component.md).

## 5. Настроить тексты, состояния и действия

Настройте состояния и обработчики по разделу
[Ручки и служебные свойства](../../testsys-web/components/README.md#ручки-и-служебные-свойства).
Для редактируемой формы прочитайте раздел [Редактируемость](../../testsys-web/components/README.md#редактируемость),
для привязок — [Привязки к сигналам](../../testsys-web/components/README.md#привязки-к-сигналам).
Тексты и размещение действий определяет [ui-design.md](../project/ui-design.md).

## 6. Проверить страницу

Страницу строит общий тест приложения; наборы параметров маршрута добавьте по разделу «Построение страниц» в
[unit-tests.md](../project/unit-tests.md#построение-страниц). Добавьте проверку действий и состояний страницы.
Проверьте параметры маршрута, повторную навигацию и ограничения доступа, если они предусмотрены сценарием.
Оформление тестов — в [unit-tests.md](../project/unit-tests.md), фоновые действия — в разделе
[Тестирование](../../testsys-web/components/README.md#тестирование).
Соберите модуль командами из [structure.md](../project/structure.md#сборка).
