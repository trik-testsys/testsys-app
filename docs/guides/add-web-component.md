# Добавление веб-компонента

Гайд ведёт разработчика от контракта компонента до работающего примера. API и контракты принадлежат
[components/README.md](../../testsys-web/components/README.md), оформление — [ui-design.md](../project/ui-design.md).

## Чек-лист

| # | Шаг | Место изменения |

| 1 | Определить контракт | API компонента |

## 1. Определить контракт

Определите смысл, допустимые состояния и размещения по требованиям и ближайшему существующему компоненту.
Статическое отображение использует `.ts-*`; ввод, фокус и оверлеи — подходящий Vaadin-компонент.
Необходимая клиентская реализация сложного интерактивного компонента подключается через ReactAdapterElement.
Она реализует тот же контракт DSL, а не вторую библиотеку компонентов.
Контракт страницы принимает только смысловую конфигурацию; границы — в
[components/README.md](../../testsys-web/components/README.md#граница-конфигурации).

## 2. Добавить DSL и ручку

Добавьте расширение нужного скоупа в пакет группы. Размещения и соглашения API — в
[components/README.md](../../testsys-web/components/README.md). Параметры описывают смысл; HTML, CSS и клиентская реализация полностью скрыты в ядре. Функция возвращает ручку
и принимает configure. Код и KDoc следуют [code-style.md](../project/code-style.md).

## 3. Добавить оформление

Используйте канонические ресурсы и правила [ui-design.md](../project/ui-design.md).
Общие классы лежат в `testsys-ui/tokens/components.css`, правила DOM Vaadin — в `testsys-ui/styles/vaadin.css`.

## 4. Добавить встроенные тексты

Добавьте контракт строк в UiTexts и сборку в buildUiTexts. Ключи добавляйте по
[add-localization.md](add-localization.md).

## 5. Проверить контракт

Используйте MockVaadinTests и buildTestPage в тестах components. Проверяйте смысловые классы, доступные имена,
состояния, запрещённые действия и изменение разметки ручкой; клиентское поведение — его исполняемыми тестами.
Соглашения тестов — [unit-tests.md](../project/unit-tests.md), сборка — [structure.md](../project/structure.md#сборка).

## 6. Показать использование

Добавьте небольшой пример совместного использования в dev-app; существующие сценарии и маршруты описаны в
[dev-app/README.md](../../testsys-web/dev-app/README.md). Внешний вид проверяйте по общим правилам интерфейса.
