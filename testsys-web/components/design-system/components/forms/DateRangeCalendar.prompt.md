Month calendar for a date or date range (registration period, contest date). Put it in a Popover under a date Input.
```jsx
<DateRangeCalendar year={2026} month={8} start={r.start} end={r.end} today="2026-09-24" onChange={setR} />
```
Mon-first weeks, weekends in tertiary ink, range = accent-soft, edges = accent.
