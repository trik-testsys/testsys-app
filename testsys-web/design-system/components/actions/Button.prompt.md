Text button for every action; one primary per block, others secondary/ghost.
```jsx
<Button variant="primary" icon="plus">Создать</Button>
<Button variant="secondary" size="sm">Изменить</Button>
<Button variant="danger" loading>Удаление…</Button>
```
Variants: primary, secondary, ghost, link, danger, danger-soft, dark. Sizes sm/md/lg. `loading` keeps colour and blocks clicks.
