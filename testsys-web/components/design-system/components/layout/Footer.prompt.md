Футтер страницы: прозрачный SVG TestSys высотой 32 px, текущий год и ссылки вызывающей страницы.
Он остаётся в обычном потоке; Page размещает его после main и заполняет окно на короткой странице.

```jsx
<Footer links={[{ label: 'Каталог компонентов', href: '../../components/index.html' }]} />
```

Имя бренда доступно через alt логотипа; год не повторяет название текстом. Пустая навигация не создаётся.
