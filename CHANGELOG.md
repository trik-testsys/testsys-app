# История изменений

Реестр изменений проекта по версиям.

## Формат записи

Версии идут от новой к старой. Изменения, которые ещё не вошли в релиз, записываются под заголовком
`## %CURRENT_VERSION%`. Первый PR после релиза добавляет заголовок заново
над предыдущей версией.

Каждый PR в `dev` добавляет в конец подходящего раздела текущей версии хотя бы одну запись:
`- Что изменилось (%PR_LINK%).` Раздел выбирается по правилам [семантического версионирования](https://semver.org/lang/ru/):

| Раздел     | Что в него попадает                                                                                   |
|------------|-------------------------------------------------------------------------------------------------------|
| `### Major` | Обновление требует ручных действий или ломает совместимость: изменён или удалён параметр приложения, изменён контракт gRPC с Проверяющим узлом, удалена фича |
| `### Minor` | Новая функциональность, которая не ломает совместимость                                              |
| `### Patch` | Исправления ошибок, рефакторинг, изменения сборки, CI и документации                                 |

Разделы идут в порядке Major, Minor, Patch. Раздел добавляется вместе с первой записью, пустые разделы
не заводятся. Номер следующей версии определяет старший раздел, в котором есть записи.

 > **Записи выпущенных версий не меняются**, кроме исправления опечаток и ссылок.

## %CURRENT_VERSION%

### Major

- Супервайзер стал Нефиксированной Ролью в Публичном Сообществе: её выдают и снимают в Служебном кабинете. 
  Супервайзеров может быть несколько. Удалены свойство
  `testsys.operation.supervisor.name` и переменная `TESTSYS_SUPERVISOR_ACCESS_TOKEN` (свойство
  `testsys.operation.supervisor.access-token`). Миграция удаляет
  прежнего Супервайзера вместе с его входами.
  Кодификаторы фич Супервайзера переименованы в `testsys.user.multi.supervisor.*`
  ([#36](https://github.com/trik-testsys/testsys-app/pull/36)).
- Добавлена обязательная переменная `TESTSYS_APP_URL` (свойство `testsys.service.app-url`) — адрес основного
  интерфейса в браузере, по которому служебный кабинет открывает страницу Пользователя в Кабинете Супервайзера
  ([#39](https://github.com/trik-testsys/testsys-app/pull/39)).

### Minor

- Страницы Кабинетов показывают шапку и заголовок сразу, а блоки с данными загружают в фоне со скелетоном; доступ к
  странице до загрузки блоков проверяют новые операции `check*`. Минимальная ширина окна уменьшена с 1440 до 1024 px,
  у таблиц появилась кнопка обновления ([#35](https://github.com/trik-testsys/testsys-app/pull/35)).
- Сессии Супервайзера, вошедшего под Пользователем, завершаются при смене Пароля, восстановлении доступа или снятии
  Роли. Супервайзер, вошедший под Пользователем, не может войти под другим Пользователем
  ([#36](https://github.com/trik-testsys/testsys-app/pull/36)).
- Вошедший Пользователь видит страницу истории изменений по версиям Системы с изменениями для своих Ролей; ссылка на
  неё стоит в футере ([#37](https://github.com/trik-testsys/testsys-app/pull/37)).
- Объявления: служебный кабинет создаёт, изменяет и закрывает объявления с типом и периодом показа, страница входа
  показывает активные ([#38](https://github.com/trik-testsys/testsys-app/pull/38)).
- Служебный кабинет: меню разделов и главная страница со списком разделов, дешифровка ID сущностей, Сообщества и Роли
  в карточке Пользователя с переходом в Кабинет Супервайзера, необязательная ссылка у объявления
  ([#39](https://github.com/trik-testsys/testsys-app/pull/39)).

### Patch

- Релиз отправляет `master`, `dev` и тег одним атомарным пушем, а merge-коммит в `dev` берёт дерево коммита релиза. Из
  Gradle-конвенций удалена строка, задвоенная слиянием релиза 1.0.0-beta.1
  ([#34](https://github.com/trik-testsys/testsys-app/pull/34)).
- Упрощён набор компонентов дизайн-системы и уточнены правила оформления: фокус, наведение, полосы прокрутки
  ([#35](https://github.com/trik-testsys/testsys-app/pull/35)).
- Тексты служебного интерфейса перенесены в сообщения локализации `page_service`
  ([#39](https://github.com/trik-testsys/testsys-app/pull/39)).
- Добавлена история изменений проекта, проверка её пополнения в PR и подстановка её секции в описание релиза GitHub
  ([#40](https://github.com/trik-testsys/testsys-app/pull/40)).
- Изменения для Пользователей, которые ещё не вошли в релиз, лежат в папке `%CURRENT_VERSION%` истории изменений
  страницы; релиз переименовывает её в номер версии. PR в `dev` обязан её пополнять, если нет метки
  `skip-user-changelog` (%PR_LINK%).
