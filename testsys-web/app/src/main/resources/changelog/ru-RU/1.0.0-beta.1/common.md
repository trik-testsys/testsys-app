## Первая бета-версия новой TestSys.

### Изменение терминологии

- Сообщество (бывшая Группа Пользователей) — набор Пользователей.
- Администратор (бывший Администратор Группы Пользователей) — Роль, наделяющая Пользователя правом создавать Сообщества и управлять ими.
- Участник (бывшая вариация Ученика) — Роль, наделяющая Пользователя правом состоять в Соревновании, принимать участие в доступных Турах.
- Ученик — Роль, наделяющая Пользователя правом состоять в Классах, принимать участие в доступных Турах.
- Соревнование — набор, состоящий из Участников, Туров и Организатора.
- Класс — набор, состоящий из Учеников, Туров и Организатора.
- Ресурс (бывший Файл) — загруженный в систему файл (в конвенциональном определении), имеющий уникальный идентификатор.

### Все Пользователи

- Добавлены вход по почте и паролю, регистрация и восстановление доступа.
- Роль теперь задаётся в рамках Сообществ.
- На каждой странице есть пошаговая инструкция.
